# CodeRank — Session Progress & Checkpoint

## How this file works
- The CLI reads this at the start of every session to know where to resume.
- After every completed task, the CLI marks it DONE here and moves to the next.
- If a session is cut off mid-task, the CLI writes a Partial State entry before stopping.
- The next session reads the Partial State and resumes from exactly that point.
- Do NOT manually edit task statuses unless you are overriding a CLI decision.

- `[DONE]` — completed and verified, flutter analyze clean
- `[IN PROGRESS]` — started this session, may be partial if session ended
- `[BLOCKED]` — needs human input or external setup; reason noted; skip and continue
- `[TODO]` — not started
